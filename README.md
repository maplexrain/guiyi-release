# 归一 Guiyi · 发布仓库

这个仓库**只放安装包与更新元数据**（`latest.yml`、`.blockmap`），源码不在这里。

## 下载

到 [Releases](https://github.com/maplexrain/guiyi-release/releases/latest) 下载最新的
`Guiyi-<版本>-Setup.exe`，双击安装即可（装进当前用户目录，不弹 UAC）。

装好之后应用会自己检查更新：发现新版本会在后台下好，下载完成后顶栏出现「↻ 更新」，
由你决定什么时候装。

## 授权

安装包是公开的，谁都能下载安装；**能不能用由授权密钥决定**（离线校验，与更新完全无关）。
第一次打开会显示本机的设备码，把它发给作者换取密钥即可激活。

安装包不含任何按买家定制的内容，升级也不会碰你的数据与授权。
